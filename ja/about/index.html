RefundJapan について

訪日旅行者のための無料・多言語対応の税金還付試算ツールです。

このツールでできること

RefundJapan は、訪日外国人の方が日本の免税ショッピングで消費税をどのくらい受け取れるかを試算できるツールです。6 つの言語に対応し、リアルタイム為替レートで母国通貨に換算した金額を表示します。

試算のしくみ

  • 標準的な消費税率：一般物品 10%、消耗品 8%。
  • 手数料：百貨店などでよく差し引かれる約 1.55% の免税手数料をオプションで反映できます。
  • リアルタイム為替：公開為替レート API から取得し、なじみのある通貨で表示します。
  • 適用条件のチェック：5,000 円の最低購入金額と 50 万円の上限は自動的に判定されます。

このツールではないもの

RefundJapan は独立したプロジェクトであり、国税庁・観光庁・いずれの店舗とも関係ありません。表示される金額はあくまで参考値の試算であり、最終的な還付額は購入日の店舗の対応と現行の制度によって決まります。
